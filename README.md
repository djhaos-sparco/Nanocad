## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **DWG Compatibility** — Seamlessly create, edit, and share drawings in the widely-used DWG format.
- **Dynamic Input & Dimensioning** — Automate drawing edits and ensure precise measurements without constant command-line use.
- **2D/3D Drafting Tools** — Support a wide range of geometric elements and drawing methods for efficient layout and design tasks.
- **Modular Extensions** — Add specialized capabilities like parametric 3D modelling and mechanical design libraries to enhance your experience.
- **Raster Editing** — Import and manipulate raster images easily within your projects.

### Advanced Features:
- **Terrain Mapping** — Create detailed terrain models for landscape architecture and civil engineering.
- **Point Cloud Import** — Effortlessly manipulate and organize large projects with named views and point cloud data.
- **User-Friendly Interface** — Familiar layout reduces the learning curve for users from other DWG-based tools.
